# Wren implementation tickets

Implementation contracts: [Wren Flutter and Dart version manager](../wren-version-manager/spec.md) and [Wren doctor](../wren-doctor/spec.md). Work is divided into ready-for-agent tickets in [issues](issues/), each with direct blocking edges. An unblocked ticket can be worked when its listed blockers are complete. The [Wren CLI architecture migration](../wren-cli-architecture/issues/01-migrate-existing-cli.md) is a prerequisite for the remaining command implementation tickets.

The [Wayfinder decision tickets](../wren-version-manager/issues/) remain separate source context. They are not implementation tickets. These build tickets and their source specs are local project files.
